The `docs-site/out/` directory is the static export build output generated by `next build`. It is listed in `docs-site/.gitignore` and must never be committed to the repository.

Flag any diff that adds or modifies files under `docs-site/out/`. If such files appear in a PR diff, they indicate the author accidentally committed build artifacts, likely by running `next build` locally and staging all files.

This rule applies to all files matching `docs-site/out/**` regardless of file type.

### Violations

```
Adding docs-site/out/_next/static/chunks/main-abc123.js to a commit
```

```
Modifying docs-site/out/index.html in a PR
```

### Compliant

```
docs-site/out/ is listed in docs-site/.gitignore and no files under it appear in any diff
```
